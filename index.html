Python runtime
Python 3.14 powered by Pyodide in a module Web Worker. Executes on your device; no Python server required. Initial runtime and libraries must download once.

Browser-first alternatives
ModernGL is represented by a WebGL 3D viewport with object selection and keyframe playback; Tkinter-style forms support event callbacks in Pyodide, and Django projects by static HTML preview only. Original native packages are not executed. PyFME is not included; the flight demonstration is a separate educational model. ASTRA Simulator Client runs against the bundled browser-compatible ASTRA engine (downloaded on first use); no server is required. Simulations are local to the IDE tab, separate from the ASTRA 3D viewer tab.
Database
SQLite files are persisted in IndexedDB on this device (up to 4 MiB each). A table browser supports create/insert/update/delete; SQLAlchemy, DuckDB and Peewee can be loaded on demand. Export data for backup.
Privacy
Your files live in browser IndexedDB. Download important projects regularly. OpenRouter receives the current Python file only when you explicitly send a prompt. If you save your personal OpenRouter key, it is encrypted locally in this browser profile using Web Crypto and IndexedDB; it is not added to GitHub or uploaded to AstraForge. The local encryption key is also held by the browser, so scripts running on this origin can access it. Use Forget key on shared devices; clearing site data also removes it.
