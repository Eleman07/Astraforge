# Holst color system — AstraForge 5.3

Reference: user-supplied image. Colors copied exactly from the six labeled swatches (dark to light):

| Hex | Intended use |
|---|---|
| `#0D1B2A` | Main background and WebGL scene backdrop |
| `#1B263B` | Status bar and layered night-blue surfaces |
| `#415A77` | Slate navigation, selection and 3D grid |
| `#778D7A` | Sage accents, focus and selected items |
| `#D4C4A8` | Sand highlights, run button, muted text and 3D object default |
| `#F4F1DE` | Ivory main text, hover accents |

Additional CSS shades are derived for separation and contrast. Text uses ivory or sand against dark backgrounds for readable contrast. Sage on the main midnight background has a contrast ratio of 4.87:1; sage on navy is only ~4.24:1, so muted text uses sand instead. Primary run button is sand on midnight blue.

The palette is entirely static, at no monetary cost. The PWA theme and icons are updated for visual consistency; installed versions can require a reload after GitHub Pages deployment.

No photo backgrounds or font files are bundled. The referenced image itself is not copied into the software.
